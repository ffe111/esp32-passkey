ESP32 Passkey

ติดตั้งเฟิร์มแวร์ passkey (FIDO2) ลง ESP32-S3 / ESP32-S2 จากเบราว์เซอร์ ไม่ต้องลงโปรแกรม

ขั้นตอน
  1. ใช้ Chrome หรือ Edge บนคอมพิวเตอร์ (Safari/Firefox ยังไม่รองรับ Web Serial)
  2. กดปุ่ม BOOT ค้างไว้ แล้วเสียบสาย USB (หรือกด RESET) เพื่อเข้าโหมดดาวน์โหลด
  3. กดปุ่มด้านล่าง เลือกพอร์ตของบอร์ด แล้วรอจนเสร็จ
  4. ถอดสายแล้วเสียบใหม่ บอร์ดจะกลายเป็น security key ใช้ได้ทันที
  5. ตั้ง PIN ด้วย passkey-cli pin set
เบราว์เซอร์นี้ไม่รองรับ Web Serial กรุณาใช้ Chrome หรือ Edge ต้องเปิดหน้านี้ผ่าน https หรือ localhost
ข้อควรรู้
  1. การติดตั้งจะลบข้อมูลเดิมในบอร์ดทั้งหมด
  2. ESP32 รุ่นแรก, C3, C6 ไม่มี USB ในตัวชิป จึงเป็น USB security key ไม่ได้ ดูทางเลือกใน README
  3. ESP32 ไม่มี secure element ความปลอดภัยต่ำกว่า YubiKey แนะนำให้ตั้ง PIN เสมอ
